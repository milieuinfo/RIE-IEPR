# RIE-IEPR Model generator

> Work in progress

De doelstelling van deze generator is dat aan de hand van:
- De ontologie
- De concepten
- De SHACL shapes

er een ER model kan gemaakt worden dat zonder ook maar enige aanpassing bruikbaar is.

De ontologie zal gebruik worden om restricties op te leggen, de concepten om vertalingen te bepalen en de SHACL shapes om polymofism toe te laten en de relaties bij de juiste entiteiten te plaatsen.
