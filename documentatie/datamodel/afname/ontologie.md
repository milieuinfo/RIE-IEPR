# Ontologie

Deze pagina wordt in de build vervangen door de door [Widoco](https://github.com/dgarijo/Widoco)
gegenereerde ontologie-documentatie (`site/ontology` -> `site/mkdocs/ontologie`).

De pagina staat als MkDocs-bron in de navigatie zodat de link naar `ontologie/` relatief
opgebouwd wordt en dus klopt onder elke basis-URL (GitHub Pages serveert de site onder
`/RIE-IEPR/`, een absoluut `/ontologie/` levert daar een 404 op).

Zie je deze tekst op de gepubliceerde site, dan is de Widoco-stap van de build mislukt.

- [riepr.ttl](https://github.com/milieuinfo/RIE-IEPR/blob/main/src/main/resources/be/vlaanderen/omgeving/riepr/data/ns/riepr/riepr.ttl) - de ontologie zelf
